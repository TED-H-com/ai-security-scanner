# v0.5.2 — Upstream engine updates

[日本語](v0.5.2.ja.md) · [繁體中文](v0.5.2.zh-TW.md) · [Release records](README.md)

This release updates ten scanning engines and their offline data for the Windows, macOS and Linux desktop app. Japanese UI support remains available in **Settings → 日本語**.

- Steampipe 2.4.7, Prowler 5.44.0, httpx 1.12.0, Semgrep 1.181.0, TruffleHog 3.99.2, Checkov 3.3.29, Trivy 0.76.0, Grype 0.120.1, Syft 1.54.1 and Kubescape 4.0.16.
- Refreshed Trivy and Grype vulnerability databases, Kubescape policies, Steampipe AWS plugin 1.34.0 and FDW 2.2.7. kube-bench receives the shared launcher update.
- Checkov's runtime dependencies now match the upstream release requirements, with dependency consistency checked during each image build.
- Grype's size check now accepts the exact verified database snapshot. The image recipes and runtime checks bind the same database fingerprints.
- Windows scan tools use WSL's native systemd support to preserve memory limits on recent WSL releases. The private scan environment stays running during scans and ends through the normal stop and removal controls. The [runtime source record](../../runtime/podman-wsl-native-systemd.md) documents the Podman backport.
- Reviewed Semgrep rules, scanner scope boundaries, native finding identifiers and Japanese translations are retained. Installer links use the current TED-H-com repository, while existing updater downloads remain compatible through the original redirect.

See the [upstream review and verification record](../engines/updates/2026-10-14.md) for exact source pins and upgrades retained for compatibility or source-verification reasons.

[v0.5.2](https://github.com/TED-H-com/ai-security-scanner/releases/tag/v0.5.2) was published as stable/latest on 2026-10-16. Windows installers remain unsigned; macOS remains unnotarized.
