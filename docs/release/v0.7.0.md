# v0.7.0 — Saved reports and portable cases

Published on 2026-11-16 at 15:05 UTC as the latest stable desktop release for Linux, macOS and Windows. [Download v0.7.0](https://github.com/TED-H-com/ai-security-scanner/releases/tag/v0.7.0).

- Save report snapshots, retrieve their original files offline and replay them with a compatible renderer.
- Create, verify and restore complete private case archives into a new workspace, preserving evidence, saved reports and recorded source-audit history. Existing desktop cases remain compatible.
- Run approved foreground scans, recover captured results and prepare selected scanners with the development CLI and pinned bootstrap.
- Admit host-led Cloudflare source audits into the shared report, including unfinished checks and items that still need validation. Improve report wording and Japanese desktop explanations.
- Publish companion CLIs with bootstrap build identity and a standalone Windows runtime archive. The post-publication bootstrap pins use the verified public files; see [bootstrap usage](../skill-bootstrap.md#prebuilt-core-from-a-pinned-release).
- Retain the v0.6.1 repository-scan security update and v0.6.2 Windows website-scan fix.

The desktop remains the default beginner entry. This delivery does not declare the complete skill-first workflow stable or switch its default. Real-host acceptance covers one Linux host; a second host, mixed assets and macOS/Windows journeys remain. No new scanner target authorization is implied by this release.

At 15:11 UTC, all 50 public files were downloaded anonymously and matched the frozen promotion artifact byte for byte. Each file's GitHub provenance verified against the promotion workflow, exact source commit and hosted runner. The current and legacy latest manifests, legacy updater redirects, checksums, metadata and updater signatures passed. Exact URLs, sizes, hashes, run selectors and observations are in the [publication receipt](v0.7.0-publication.json).

Windows installers remain unsigned and macOS is not notarized. macOS and Windows NSIS have signed updater payloads; Linux DEB and Windows MSI have no updater payload. AppImage and RPM are not offered. Exact-candidate human beginner-path checks and the separate Windows lifecycle/data-preservation qualification were not observed; the receipt preserves these distinctions.

The preceding nonpublishing [QC run](https://github.com/TED-H-com/ai-security-scanner/actions/runs/43859962022) used the previous main revision. Its first NSIS check failed at the second runtime stop without diagnostic output; rerunning the unchanged installer passed. The cause remains unconfirmed. The actual v0.7.0 candidate's NSIS check passed on its first attempt, as did the other three installer checks.

新增報告快照、離線原檔取回與相容 renderer 的重播，以及可驗證、還原到新工作區的完整私人案件封存，保留證據、報告與已記錄的原始碼稽核歷史，並相容既有桌面案件。開發中的 CLI 與釘選 bootstrap 支援前景掃描、結果復原及所選掃描器準備；Cloudflare 宿主稽核可進入共用報告，包含未完成檢查與待驗證項目。改善報告用詞與日文桌面說明，保留 v0.6.1 安全性更新與 v0.6.2 Windows 網站掃描修正。

各平台 CLI 已帶入後續預建核心釘選所需的識別，Windows 另附獨立掃描執行環境封存；發布後的 bootstrap 釘選使用已驗證的公開檔案，操作方式見 [bootstrap 文件](../skill-bootstrap.md#prebuilt-core-from-a-pinned-release)。桌面版維持初學者預設入口，完整 skill-first 流程仍在開發中。目前僅一台 Linux 主機完成實機驗收，第二宿主、多資產及 macOS／Windows 旅程尚待驗證。

精確來源的 CI、CodeQL、候選與發布流程均通過；正式候選的 DEB、DMG、MSI、NSIS 四種安裝驗證一次完成，沒有重跑。Linux 與兩種 Windows 安裝檔通過執行環境及受控引擎檢查；macOS 通過安裝、桌面啟動與清理，但 hosted 主機未觀察到執行環境運作。

發布前、不公開的 QC 使用先前 main：NSIS 第一次在第二次停止執行環境時失敗，原成品重跑通過，原因尚未確認。正式 v0.7.0 候選的同一檢查第一次即通過；這兩次觀察都保留在紀錄中。
