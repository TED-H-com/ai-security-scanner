# v0.6.0 — upstream engines and runtime refresh

This release updates the scanning tools, their reviewed rules and offline data, and the private scan runtime. Choose the same guided scan paths and get one report with the original scanner evidence and practical next steps.

- Reviews all 25 integrated engines, publishes and independently verifies 18 replacement managed images, and activates the official KICS 2.2.0 image.
- Updates Greenbone to 23.52.9 with November 6 feeds, Garak to 0.17.1, Semgrep to 1.184.0, Trivy to 0.76.2, Grype to 0.121.2, and the other selected compatible releases. Nuclei uses 4,777 admitted safe HTTP templates from v10.5.1.
- Updates Microsoft 365 checks to Maester 2.3.0 and ScubaGear 2.0.0 with PowerShell 7.6.9. Existing read-only permission and asset boundaries remain unchanged.
- Updates the private runtime to Podman 5.8.9 / machine OS 5.8.9-1, QEMU 11.1.3, gvproxy 0.9.0 and vfkit 0.6.4.
- Updates application dependencies and the ZIP report library, addressing its upstream HMAC, symlink-size and dual-header advisories.
- Rebases the Windows installer template onto Tauri CLI 2.12.4, including upstream path quoting and downgrade checks while retaining the product's bounded repair and uninstall behavior.

The [upstream review](../engines/updates/2026-11-06.md) lists every engine and the reasons for compatibility choices. CloudQuery uses CLI 3.5.3 with its retained public plugins; newer CLI releases cannot run that plugin protocol. Podman stays on the maintained 5.8 line to retain existing desktop platforms. Semgrep retains the reviewed legacy rule pack and its redistribution terms. These retained inputs and their coverage dates remain visible in the catalog.

The [engine publication receipts](../engines/updates/2026-11-06-publications.json) bind the exact public image digests, source commits, both platform identities and verified source/SBOM attestations. Greenbone and Semgrep passed native amd64 and arm64 execution; other image records distinguish platform identity from their recorded amd64 execution. No credentialed customer or cloud scan was run for this update.
