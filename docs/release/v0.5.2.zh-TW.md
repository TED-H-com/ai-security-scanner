# v0.5.2 — 上游引擎更新

[English](v0.5.2.md) · [日本語](v0.5.2.ja.md) · [發布紀錄](README.zh-TW.md)

本版更新 Windows、macOS 與 Linux 桌面程式的十個掃描引擎與離線資料。日文介面仍可從 **設定 → 日本語** 選擇。

- 更新 Steampipe 2.4.7、Prowler 5.44.0、httpx 1.12.0、Semgrep 1.181.0、TruffleHog 3.99.2、Checkov 3.3.29、Trivy 0.76.0、Grype 0.120.1、Syft 1.54.1、Kubescape 4.0.16。
- 刷新 Trivy、Grype 弱點資料庫與 Kubescape 政策；Steampipe AWS 外掛更新為 1.34.0、FDW 為 2.2.7，kube-bench 同步更新共用啟動器。
- 修正 Checkov 執行環境的相依套件版本，並在映像建置時確認套件相容性。
- 修正新版 Grype 資料庫超出原大小限制的問題，建置配方與執行時核對相同的資料雜湊。
- Windows 掃描工具改用 WSL 原生 systemd，在新版 WSL 維持記憶體限制，避免掃描時因閒置判定中斷；停止與移除會一併結束私有掃描環境。[執行環境來源紀錄（英文）](../../runtime/podman-wsl-native-systemd.md)記載了 Podman 的回移修補。
- 保留已驗證的 Semgrep 規則、掃描範圍限制、原始發現識別碼與日文翻譯。安裝檔下載連結使用目前的 TED-H-com 儲存庫；應用程式更新保留原有網址，透過 GitHub 儲存庫轉址下載。

精確來源、驗證結果與暫緩升級的原因，見[上游更新紀錄](../engines/updates/2026-10-14.md)。

[v0.5.2](https://github.com/TED-H-com/ai-security-scanner/releases/tag/v0.5.2) 已於 2026-10-16 發布為 stable／latest。Windows 安裝檔仍未簽章，macOS 仍未公證。

## 正式交付

[候選 38828427832](https://github.com/TED-H-com/ai-security-scanner/actions/runs/38828427832) 建置精確來源 `7af85506691028b3e52d2c3c0cb2a5af0d092b3c`；[發布流程 38834571528](https://github.com/TED-H-com/ai-security-scanner/actions/runs/38834571528) 經正常 `release-publication` 核准後直接發布同一批凍結檔案，沒有重新建置。

全部 49 個公開檔案均已匿名下載，大小與 SHA-256 符合凍結檔案，並通過精確來源的建置證明驗證。macOS／Windows NSIS 更新簽章、最新版入口及舊更新網址轉址也已驗證。[正式交付清單](v0.5.2-publication.json)保留每個安裝檔的檢查碼。

Linux DEB 與 Windows MSI／NSIS 通過安裝、桌面啟動及 managed runtime 檢查。Windows 另通過受限容器與出口閘道、閒置 30 秒、停止再啟動後再閒置 30 秒，以及使用同一安裝版 runtime manifest 的清理檢查。macOS DMG 通過安裝與桌面啟動；qualification 主機未觀察 runtime 執行。Windows 已安裝程式生命週期、升級／資料保留及精確候選新手真人路徑仍未觀察，不提供 AppImage 與 RPM。

[精確來源 CI](https://github.com/TED-H-com/ai-security-scanner/actions/runs/38828407274) 與 [CodeQL](https://github.com/TED-H-com/ai-security-scanner/actions/runs/38828407119) 均通過。最終來源通過 102 項 CI 合約、發布自測與 221 項發布證據測試；候選版本另通過 943 項前端測試。Windows CI 在產生安裝檔前，以實際建置的 CLI 讀取完整 runtime bundle，並核對桌面程式信任錨點。新版下載頁完成三語、兩種寬度共六組瀏覽器檢查，另通過七項網站及 17 項文件／助手指引合約。

網站、三語 README、安裝指南及兩份助手安裝指引已同步指向 v0.5.2。
