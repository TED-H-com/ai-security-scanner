# v0.5.2 — 上游引擎更新

[English](v0.5.2.md) · [日本語](v0.5.2.ja.md) · [發布紀錄](README.zh-TW.md)

本版更新 Windows、macOS 與 Linux 桌面程式的十個掃描引擎與離線資料。日文介面仍可從 **設定 → 日本語** 選擇。

- 更新 Steampipe 2.4.7、Prowler 5.44.0、httpx 1.12.0、Semgrep 1.181.0、TruffleHog 3.99.2、Checkov 3.3.29、Trivy 0.76.0、Grype 0.120.1、Syft 1.54.1、Kubescape 4.0.16。
- 刷新 Trivy、Grype 弱點資料庫與 Kubescape 政策；Steampipe AWS 外掛更新為 1.34.0、FDW 為 2.2.7，kube-bench 同步更新共用啟動器。
- 修正 Checkov 執行環境的相依套件版本，並在映像建置時確認套件相容性。
- 修正新版 Grype 資料庫超出原大小限制的問題，建置配方與執行時核對相同的資料雜湊。
- Windows 掃描工具改用 WSL 原生 systemd，在新版 WSL 維持記憶體限制，避免掃描時因閒置判定中斷；停止與移除會一併結束私有掃描環境。[執行環境來源紀錄（英文）](../../runtime/podman-wsl-native-systemd.md)記載了 Podman 的回移修補。
- 保留已驗證的 Semgrep 規則、掃描範圍限制、原始發現識別碼與日文翻譯。安裝檔下載連結使用目前的 TED-H-com 儲存庫；應用程式更新保留原有網址，透過 GitHub 儲存庫轉址下載。

精確來源、驗證結果與暫緩升級的原因，見[上游更新紀錄](../engines/updates/2026-10-14.md)。

Windows 安裝檔仍未簽章，macOS 仍未公證。預計提供 Windows NSIS／MSI、macOS Universal DMG 與 Linux x86-64 DEB；公開發布與最終檔案驗證仍在準備中。
