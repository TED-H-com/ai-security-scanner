# v0.5.1 — Japanese support

[日本語](v0.5.1.ja.md) · [繁體中文](v0.5.1.zh-TW.md) · [Release records](README.md)

This release packages Japanese UI support for Windows, macOS and Linux. [v0.5.1](https://github.com/teddashh/ai-security-scanner/releases/tag/v0.5.1) was published as stable/latest on 2026-10-12.

- Choose **Settings → 日本語**; the choice persists across restarts.
- Includes [@kieiken](https://github.com/kieiken)'s [#69](https://github.com/teddashh/ai-security-scanner/pull/69) translation and follow-up translations for onboarding, scan setup and runtime preparation.
- Adds a [Japanese README](../../README.ja.md) and [Japanese website](https://teddashh.github.io/ai-security-scanner/?lang=ja), including all 25 scanner introductions, search and language persistence.
- Untranslated explanations fall back to English. HTML exports from the Japanese UI and existing sample report downloads use English.

Scanner behavior and scope boundaries are unchanged. Windows installers remain unsigned and macOS remains unnotarized.
