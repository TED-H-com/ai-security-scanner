# v0.5.1 — 日本語対応

[English](v0.5.1.md) · [繁體中文](v0.5.1.zh-TW.md)

Windows・macOS・Linux のデスクトップアプリに日本語 UI を追加します。現在インストーラーを準備中です。公開後に配布情報を追記します。

- **Settings → 日本語** で切り替えられます。選択した言語は再起動後も保存されます。
- [@kieiken](https://github.com/kieiken) さんの [#69](https://github.com/teddashh/ai-security-scanner/pull/69) の翻訳を取り込み、初期設定、スキャンの設定、スキャン環境の準備に残っていた未翻訳箇所も補いました。
- [日本語 README](../../README.ja.md) と [日本語 Web サイト](https://teddashh.github.io/ai-security-scanner/?lang=ja) を追加しました。全 25 スキャナーの紹介、検索、言語選択の保存に対応しています。
- 未翻訳の説明は英語で表示されます。日本語 UI からエクスポートする HTML レポートと既存のサンプルレポートは、現時点では英語です。

スキャナーの動作とスキャン範囲の制限は従来どおりです。Windows インストーラーは未署名、macOS アプリは未公証です。
