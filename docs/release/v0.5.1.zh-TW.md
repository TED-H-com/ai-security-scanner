## 正式交付

[候選 38280286730](https://github.com/teddashh/ai-security-scanner/actions/runs/38280286730) 建置精確來源 `0405fecbf3435d16da176fc5be2ab14fcb4c962f`；[發布流程 38286089269](https://github.com/teddashh/ai-security-scanner/actions/runs/38286089269) 經正常 `release-publication` 核准後，直接發布同一批凍結檔案，沒有重新建置。

全部 49 個公開檔案已匿名下載，大小與 SHA-256 均符合凍結檔案，並通過精確來源的建置證明驗證。macOS／Windows NSIS 更新簽章、版本 tag 與最新版入口也已驗證。[正式交付清單](v0.5.1-publication.json)保留每個安裝檔的檢查碼。

Linux DEB 與 Windows MSI／NSIS 通過安裝、桌面啟動及 managed runtime 檢查。macOS DMG 通過安裝與桌面啟動；qualification 主機未觀察 runtime 執行。Windows 生命週期／資料保留及精確候選新手真人路徑仍未觀察，不提供 AppImage 與 RPM。

精確來源 CI 與 CodeQL 均通過，包含 942 項前端、571 項元件及 2,213 項 Rust 測試；發布自測與 203 項發布證據測試也通過。新版下載頁完成三語、兩種寬度共六組瀏覽器檢查，另通過八項網站及 17 項文件／助手指引契約。

網站、三語 README、安裝指南及兩份助手安裝指引已同步指向 v0.5.1。
