# v0.6.2 — Windows website scan fix

Fix for website scans in the Windows desktop app.

- On Windows, the app no longer refuses to start page response checks (ZAP). Since v0.4.0 it stopped this check before contacting the website and showed "the ZAP report directory must be an absolute path".
- The check uses the same website limits, request rate and timeouts as on macOS and Linux.
- Nothing else changes: macOS and Linux behave as in v0.6.1, and scanning tools, existing cases, reports and settings stay the same.

Includes the [v0.6.1 security update](v0.6.1.md): [GHSA-6w49-gw8c-q7wp](https://github.com/TED-H-com/ai-security-scanner/security/advisories/GHSA-6w49-gw8c-q7wp).

The release workflows build and promote only from `main`, which already contained unreleased development work, so the exact release source `be27aea` (parent `f4695e6`) carries the released v0.6.1 tree plus only this fix, the version and the notes. Commit `0a1bec5` restores the development tree; development commits in the tag's history are not changes included in this release.

## 繁體中文

修正 Windows 桌面版的網站掃描。在 Windows 上，程式不再拒絕啟動「頁面回應檢查（ZAP）」；從 v0.4.0 起，這項檢查會在連線網站之前就停止，並顯示「the ZAP report directory must be an absolute path」。檢查使用與 macOS、Linux 相同的網站範圍、請求速率與逾時設定。其他內容與 v0.6.1 相同：macOS 與 Linux 不受影響，掃描工具、既有案件、報告與設定都不變。

本版包含 [v0.6.1 安全性更新](v0.6.1.md#繁體中文)（[GHSA-6w49-gw8c-q7wp](https://github.com/TED-H-com/ai-security-scanner/security/advisories/GHSA-6w49-gw8c-q7wp)）。發布流程只從 `main` 建置與發布，而 `main` 已有未發布的開發內容，因此精確來源 `be27aea`（父提交 `f4695e6`）採用已發布 v0.6.1 的檔案樹，只加入本次修正、版本與說明。`0a1bec5` 恢復開發中的檔案樹；標籤歷史中的開發提交不代表那些功能包含在本版。

全新 runner 的 Linux DEB、Windows MSI 與 NSIS 狀態為 `passed`，包含啟動、專用執行環境操作、隔離 Gitleaks 容器檢查、出口閘道就緒與清理。macOS DMG 為 `installer_passed_runtime_not_observed`：啟動與清理通過，但 hosted runner 不支援巢狀虛擬化，未觀察執行環境操作。Windows 安裝檔未簽章，macOS 未公證；不提供 Linux AppImage 與 RPM。各成品的狀態與限制保存在[發布查核紀錄](v0.6.2-publication.json)。
