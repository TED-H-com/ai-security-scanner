# v0.5.2 — スキャンエンジンの更新

[English](v0.5.2.md) · [繁體中文](v0.5.2.zh-TW.md)

Windows・macOS・Linux 向けアプリのスキャンエンジン 10 個とオフラインデータを更新します。日本語 UI は引き続き **Settings → 日本語** で選択できます。

- Steampipe 2.4.7、Prowler 5.44.0、httpx 1.12.0、Semgrep 1.181.0、TruffleHog 3.99.2、Checkov 3.3.29、Trivy 0.76.0、Grype 0.120.1、Syft 1.54.1、Kubescape 4.0.16 に更新。
- Trivy・Grype の脆弱性データベースと Kubescape のポリシーを刷新。Steampipe の AWS プラグインを 1.34.0、FDW を 2.2.7 に更新し、kube-bench の共通ランチャーも更新。
- Checkov の依存パッケージを上流リリースの要件に合わせ、イメージの構築時に依存関係の整合性を確認。
- 新しい Grype データベースの容量に対応し、イメージの構築と実行時で同じデータのハッシュを確認。
- Windows のスキャン環境は WSL のネイティブ systemd を使用し、新しい WSL でもメモリ上限を維持します。スキャン中のアイドル停止を防ぎ、通常の停止・削除操作で終了します。[実行環境のソース記録（英語）](../../runtime/podman-wsl-native-systemd.md)に Podman のバックポートを記載しています。
- 確認済みの Semgrep ルール、スキャン対象の制限、検出結果の識別子、日本語 UI を維持。インストーラーのダウンロード先は現在の TED-H-com リポジトリです。アプリ内更新のダウンロード URL は従来のものを維持し、GitHub のリダイレクトを利用します。

詳細は[上流バージョンの確認・検証記録（英語）](../engines/updates/2026-10-14.md)を参照してください。

Windows インストーラーは未署名、macOS アプリは未公証です。Windows NSIS／MSI、macOS Universal DMG、Linux x86-64 DEB を提供予定です。公開と配布ファイルの最終確認は準備中です。
